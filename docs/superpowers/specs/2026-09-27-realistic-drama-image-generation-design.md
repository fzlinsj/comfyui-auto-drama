# 真人漫剧生图修正设计

## 目标

让 ComfyUI 生图链路默认生成符合真实世界摄影逻辑的真人漫剧素材：真人角色像演员剧照，动物角色保持真实动物形象，场景和道具保持现实材质与时代环境；禁止把动物套用成人物肖像模板，也禁止在 checkpoint 未明确时静默使用不确定的默认模型。

## 已确认根因

- `console/index.html` 的角色默认提示词固定包含“半身肖像照、真人照片、单一人像”等人物模板，并以“根据名字与描述判断性别”兜底，导致真实动物被错误生成人物、古画或文字内容。
- 性别推断只覆盖少量人类关键词，无法区分动物、男性和女性角色。
- `workflows/build_sdxl_graph.py` 在 checkpoint 为空时回退到 `sd_xl_base_1.0.safetensors`；这会掩盖配置错误，并可能与用户在 ComfyUI 页面实际使用的模型不一致。
- 当前标准 SDXL 工作流没有 IPAdapter、InstantID 或 ControlNet 条件输入，因此本次先保证提示词和模型配置正确，不承诺跨镜头的人脸完全一致。

## 设计范围

### 1. 角色类型分类

新增纯函数式分类逻辑，至少支持三类：

- `human_male`：明确男性词或用户手动选择“男”。
- `human_female`：明确女性词或用户手动选择“女”。
- `animal`：常见动物名称（包括“公鸡”）或用户手动选择“动物”。

无法可靠判断时使用 `unknown`，但不再生成“根据名字与描述判断性别”这类含糊指令；界面允许用户选择类型覆盖自动判断。

### 2. 真人漫剧提示词模板

- 真人男性/女性：保留时代、身份、发型、服装和角色描述，加入真实演员、电影剧照、自然光、真实皮肤与服装材质等约束。
- 真实动物：加入明确物种、真实动物摄影、自然姿态、毛发/羽毛/皮肤细节和环境光；禁止“人脸、人体、双眼有神、服装穿戴、半身人像”等人物词，除非角色描述明确要求拟人化（本项目当前不使用拟人化）。
- 未知类型：采用中性现实世界主体模板，不强行添加人类性别或人物肖像词。

所有模板统一加入负面约束：文字、字幕、logo、水印、书法、古画、插画、二次元、卡通、3D 渲染、拼接、重复主体、额外人物、畸形肢体和低清晰度。

### 3. ComfyUI 模型与采样配置

- `image_gen.comfyui.checkpoint` 必须是非空字符串。
- 提交前通过 ComfyUI `/object_info` 或现有预检接口确认 checkpoint 可用；为空或不可用时返回明确错误，指出配置位置和可选模型，不提交任务。
- 采样参数继续从配置/端点传入（尺寸、steps、CFG、sampler、scheduler），保留现有 SDXL 默认值作为显式配置的最后一层，仅在参数未设置时使用。
- 本次不修改工作流节点拓扑，不假设额外自定义节点存在。

## 数据流

1. 前端读取角色描述、资产状态和用户类型选择。
2. 前端生成并展示对应类型的默认角色提示词；用户手工编辑后，保存的提示词优先级最高。
3. `/api/asset_gen` 接收提示词和 `expected` 元数据；后端在调用 ComfyUI 前合并通用负面约束，并从 `config.json` 读取 checkpoint 与采样参数。
4. 后端执行 checkpoint 预检；失败时返回可操作错误，不生成错误资产。
5. 成功生成后沿用现有媒体保存、质量检查和资产状态更新流程。

## 错误处理

- 缺少 checkpoint：返回“请在 config.json 的 image_gen.comfyui.checkpoint 配置实际模型文件名”。
- checkpoint 不在 ComfyUI 可用列表：返回模型名和 ComfyUI 服务地址，提示刷新模型列表或修改配置。
- 无法判断角色类型：使用 `unknown` 中性模板，并在资产卡片保留手动类型选择；不因分类不确定而生成具有人类性别的提示词。
- 用户已保存的自定义提示词不被自动覆盖；切换类型时只更新默认模板，用户再次编辑后才提交新内容。

## 测试与验收

- Python 单元测试覆盖：checkpoint 为空/有效/不可用、通用负面词合并、采样参数传入和错误信息。
- JavaScript 逻辑测试或静态回归检查覆盖：男性、女性、动物（“公鸡”）、未知分类的模板关键词，以及不再出现模糊性别兜底句。
- `py_compile`、现有 `console/tests` 全量测试和 `git diff --check` 通过。
- 手工验收：使用一个真人角色和“公鸡”各生成一张锚点图；真人图不出现动物主体，公鸡图不出现人类身体/人脸/文字；控制台日志显示实际 checkpoint 与采样参数。

## 非目标

- 本次不接入 IPAdapter、InstantID、ControlNet 或新的模型下载流程。
- 本次不修改已经保存的历史图片，只影响新生成的资产和重新生成操作。
